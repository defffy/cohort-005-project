# Approved Refunds permanently delete Progress

When an Admin approves a Refund on a Purchase for the User's own access, the User's Progress in the course (completed lessons, video watched, quiz attempts) and their rating of it are permanently deleted, not archived. We chose a hard delete because the User has given the course back: if they buy it again they start afresh, and keeping hidden copies would mean filtering refunded Progress out of every place that reads it. The Refund itself records that it was Approved, by whom and when. Comments are kept, because deleting them would break other people's reply threads.

## Consequences

Progress cannot be recovered after approval, so Refund Eligibility can't be re-checked against it afterwards. Admins see the User's current Progress, flagged against the eligibility limits, before they approve.
